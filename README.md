# AI-Powered Financial Analysis & Forecasting – HUL

An integrated Finance + AI project analysing Hindustan Unilever Limited (HUL) using a 5-year Excel financial model and a Streamlit-based AI application.

## Project Overview

The project combines traditional financial analysis with AI-assisted interpretation to evaluate HUL's historical performance, profitability, working-capital efficiency, forecasts and valuation.

Financial period analysed: FY2020-21 to FY2024-25  
Financial basis: Standalone Financial Statements  
Currency: ₹ Crore

## Excel Financial Model

The Excel workbook includes:

- 5-year financial statement analysis
- Revenue, EBITDA and PAT growth analysis
- Profitability margins
- ROE and ROCE analysis
- Working Capital and Cash Conversion Cycle
- Common-Size and Trend Analysis
- DuPont ROE Analysis
- Bear, Base and Bull Forecasts for FY26-FY28
- P/E and EV/EBITDA Valuation
- Valuation Sensitivity Analysis
- Interactive Financial Dashboard
- Management Insights

## Finance AI Application

The Streamlit application provides:

- AI Financial Performance Analysis
- Annual Report Q&A
- Page-level source citations
- AI Risk & Opportunity Detection
- Bear / Base / Bull Forecast Analysis
- Sensitivity Analysis
- P/E and EV/EBITDA Valuation
- AI-assisted Valuation Interpretation
- Interactive Plotly visualisations

## Key Financial Insights

- HUL revenue increased from ₹45,311 Cr in FY21 to ₹60,680 Cr in FY25.
- Revenue CAGR was approximately 7.6%.
- EBITDA margin remained strong although it moderated from around 25% to 23.5%.
- FY25 ROE reached approximately 21.3%.
- HUL maintained a negative Cash Conversion Cycle, reflecting efficient working-capital management.
- Base Case FY28 revenue is estimated at approximately ₹70,245 Cr.

## Valuation

The project applies two multiples-based valuation approaches:

- P/E based Equity Valuation
- EV/EBITDA based Equity Valuation

Sensitivity analysis demonstrates how changes in valuation multiples affect implied equity value.
